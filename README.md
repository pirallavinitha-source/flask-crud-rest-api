# Flask CRUD REST API

A containerized **CRUD REST API** built using **Python Flask, SQLAlchemy, PostgreSQL, Docker, and Docker Compose**.

This project provides RESTful APIs to create, retrieve, update, and delete user information stored in a PostgreSQL database.

## 🚀 Features

* Create a new user
* Get all users
* Get a user by ID
* Update user details
* Delete a user
* PostgreSQL database integration
* SQLAlchemy ORM
* Dockerized Flask application
* Docker Compose for Flask and PostgreSQL
* API testing using Postman
* JSON-based request and response handling

## 🔄 CRUD Operations

| Operation | HTTP Method | Endpoint      | Description         |
| --------- | ----------- | ------------- | ------------------- |
| Create    | POST        | `/users`      | Create a new user   |
| Read All  | GET         | `/users`      | Get all users       |
| Read One  | GET         | `/users/<id>` | Get a user by ID    |
| Update    | PUT         | `/users/<id>` | Update user details |
| Delete    | DELETE      | `/users/<id>` | Delete a user       |

## 📥 API Input

The API accepts user information in **JSON format**.

### Create User

**Endpoint:**

```text
POST /users
```

**Request Body:**

```json
{
    "username": "vinitha",
    "email": "vinitha@example.com"
}
```

The user provides:

* `username`
* `email`

The `id` is automatically generated by the database.

## 📤 API Output

After successfully creating a user, the API returns a JSON response:

```json
{
    "message": "user created",
    "user": {
        "id": 1,
        "username": "vinitha",
        "email": "vinitha@example.com"
    }
}
```

## 🐳 Running the Project with Docker

### Prerequisites

Make sure the following are installed:

* Python
* Docker Desktop
* Git
* Postman

### 1. Clone the Repository

```bash
git clone https://github.com/pirallavinitha-source/flask-crud-rest-api.git
```

### 2. Open the Project Directory

```bash
cd flask-crud-rest-api
```

### 3. Start the Application

```bash
docker compose up -d
```

This starts:

* Flask application container
* PostgreSQL database container

### 4. Check Running Containers

```bash
docker ps
```

The Flask API will be available at:

```text
http://localhost:4000
```
