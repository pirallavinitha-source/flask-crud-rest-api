\# Flask CRUD REST API



A simple \*\*CRUD REST API\*\* built using \*\*Python Flask, SQLAlchemy, PostgreSQL, Docker, and Docker Compose\*\*.



This project provides APIs to create, retrieve, update, and delete user information stored in a PostgreSQL database.



\## 🚀 Features



\* Create a new user

\* Get all users

\* Get a user by ID

\* Update user details

\* Delete a user

\* PostgreSQL database integration

\* SQLAlchemy ORM

\* Dockerized Flask application

\* Docker Compose for Flask and PostgreSQL

\* API testing using Postman



\## 🛠️ Technologies Used

\## 🔄 CRUD Operations



The API provides the following endpoints:



| Operation | HTTP Method | Endpoint      | Description         |

| --------- | ----------- | ------------- | ------------------- |

| Create    | POST        | `/users`      | Create a new user   |

| Read All  | GET         | `/users`      | Get all users       |

| Read One  | GET         | `/users/<id>` | Get a user by ID    |

| Update    | PUT         | `/users/<id>` | Update user details |

| Delete    | DELETE      | `/users/<id>` | Delete a user       |



\## 📥 Input



For creating a user, send JSON data containing a username and email.



\### POST `/users`



```json

{

&#x20;   "username": "vinitha",

&#x20;   "email": "vinitha@example.com"

}

```



\## 📤 Output



After successfully creating a user, the API returns:



```json

{

&#x20;   "message": "user created",

&#x20;   "user": {

&#x20;       "id": 1,

&#x20;       "username": "vinitha",

&#x20;       "email": "vinitha@example.com"

&#x20;   }

}

```



The `id` is automatically generated by the database.



\## 🐳 Running the Project with Docker



\### 1. Clone the repository



```bash

git clone <your-github-repository-url>

```



\### 2. Open the project directory



```bash

cd flask-crud-live

```



\### 3. Start the containers



```bash

docker compose up -d

```



This starts two containers:



\* Flask application

\* PostgreSQL database



\### 4. Check running containers



```bash

docker ps

```



The Flask API runs on:



```text

http://localhost:4000

```



\## 🧪 Testing the API



The API can be tested using \*\*Postman\*\*.



\### Test Route



```text

GET http://localhost:4000/test

```



Expected response:



```json

{

&#x20;   "message": "test route"

}

```



\### Create User



```text

POST http://localhost:4000/users

```



Body → raw → JSON:



```json

{

&#x20;   "username": "vinitha",

&#x20;   "email": "vinitha@example.com"

}

```



\### Get All Users



```text

GET http://localhost:4000/users

```



\### Get User by ID



```text

GET http://localhost:4000/users/1

```



\### Update User



```text

PUT http://localhost:4000/users/1

```



Body:



```json

{

&#x20;   "username": "vinitha\_updated",

&#x20;   "email": "vinitha\_updated@example.com"

}

```



\### Delete User



```text

DELETE http://localhost:4000/users/1

```
